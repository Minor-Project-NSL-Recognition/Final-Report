\chapter{LITERATURE REVIEW}
\label{ch:litreview}

Sign language recognition sits at the intersection of computer vision and sequence modelling. Published work divides along two axes: whether the input is raw pixels or extracted landmarks, and whether the signs studied are static handshapes or motion. Emergency phrases are whole dynamic signs, so this project is concerned with the landmark-based and temporal branches of the field. This chapter reviews the works closest to that problem, summarises them, states the gap they leave, and then sets out the theory the system is built on.

\section{Review of Related Works}

Each work below is summarised in the same order: what it did, what it establishes, what it leaves open, and how this project differs from it.

\subsection{ASL Character Recognition Using CNN (Masood et al., 2018)}
Masood et al. \cite{masood2018aslchar} trained a convolutional neural network on raw images for American Sign Language character recognition and reported strong accuracy on a large image dataset.

Its strength is a clear demonstration that convolutional networks handle static fingerspelling well when data is plentiful. Its limitations are the corollary: it illustrates how much data a pixel-based model needs, and it does not address motion at all. This project differs in both respects. It classifies whole dynamic phrases rather than held handshapes, and it reaches the accuracies of Chapter~\ref{ch:results} from 840 clips because the landmark representation removes the appearance variation a pixel model must spend data learning to ignore.

\subsection{Word-Level Sign Recognition Using CNN and RNN (Masood et al., 2018)}
In a companion paper, Masood et al. \cite{masood2018slword} combined a convolutional network with a recurrent network to recognise word-level gestures from video.

Its strength is the pattern it establishes: spatial feature extraction paired with temporal modelling for dynamic signs. That is the same principle applied here. Its limitation is cost, since a convolutional network runs on every frame. This project differs by moving the spatial half of that pairing into a pretrained landmark extractor, which is what leaves a classifier small enough to run on a phone.

\subsection{NSL Translation Using CNN (Mali et al., 2018)}
Mali et al. \cite{mali2018nsl} built one of the earliest NSL recognition systems, a convolutional translator over a very small vocabulary.

Its strength is priority. It established NSL recognition as a problem worth attempting and produced a working system for it. Its limitations are that the signer had to wear red gloves at test time and that only static gestures were handled. This project differs by requiring no gloves, markers, or depth sensors, and by recognising motion rather than posture.

\subsection{Deep Learning for NSL Gesture Recognition (Ligal and Baral, 2022)}
Ligal and Baral \cite{ligal2022nsl} explored deep architectures for NSL gesture recognition, pairing a convolutional network with a recurrent network in one variant and with a Vision Transformer in another.

Its strength is breadth: it surveys several modern architectures on NSL rather than committing to one, and confirms sustained research interest in the language. Its limitations are that it keeps the pixel-based formulation and targets neither emergency communication nor deployment on modest hardware. This project differs by fixing the architecture and varying the evaluation instead, and by treating the deployment target as a constraint on the model from the outset.

\subsection{ISL Recognition Using MediaPipe Holistic (Goyal and Velmathi, 2023)}
Goyal and Velmathi \cite{goyal2023isl} applied MediaPipe Holistic to Indian Sign Language, using LSTMs for dynamic signs and convolutional networks for static ones.

Its strength is the support it gives to the landmark-plus-temporal-model direction: landmarks from a pretrained extractor, fed to a temporal model, are sufficient for dynamic signs. Its limitations for this project's purposes are that it targets a well-resourced language at individual-sign level, reports no signer-held-out protocol, and produces no audio output. This project applies the same direction where none of those conditions hold. NSL had no dynamic dataset to work from, the unit of recognition is a whole emergency phrase rather than a single sign, every accuracy is measured on an unseen signer, and the result is spoken aloud in Nepali.

\subsection{NSL Letter Detection Using MediaPipe and CNN (Shrestha et al., 2024)}
Shrestha et al. \cite{shrestha2024nsl} present the closest prior landmark-based NSL system. MediaPipe landmarks are re-rendered as skeleton images and a convolutional network is trained on those images, with high reported accuracy.

Its strength is the confirmation that MediaPipe extracts usable NSL hand geometry, which is the premise this project depends on. Two limitations follow from the design. It converts numeric landmark geometry back into pixels rather than feeding the sequence to a temporal model, which discards the ordering that a phrase is carried in. And its evaluation does not separate signers between training and test, so the reported accuracy does not establish how the system behaves on a person it has not seen. This project differs on exactly those two points. The landmark sequence goes to the model as numbers, and every accuracy in Chapter~\ref{ch:results} is measured on a signer absent from training. The second of these is the contribution stated in Section~\ref{sec:contributions}.

\subsection{NSL Characters Recognition with Deep Learning (Poudel et al., 2025)}
Poudel et al. \cite{poudel2025nsl} introduced a 36-class static image dataset and reported roughly 90\% accuracy with fine-tuned MobileNetV2 and ResNet50 networks.

Its strength is the dataset. Public NSL data is scarce, and a released 36-class set is a contribution independent of the accuracies reported on it. Its limitation is that the set is static images, which leaves motion-based phrase signs unaddressed. It is also the most recent work reviewed here, so it shows the static-image formulation still dominating NSL research in 2025. This project differs by recording a dynamic dataset instead, and by targeting the phrases a person would need under pressure rather than the alphabet.

\section{Research Gap}
\label{sec:researchgap}
The gap is therefore not that NSL recognition is unstudied, but that everything studied so far answers a different question from the one an emergency tool has to answer. Four specific gaps follow from the works above, and together they define this project:

\begin{enumerate}
    \item No public NSL dataset or recognition system exists for emergency phrases. All published NSL work targets the fingerspelling alphabet or isolated characters.
    \item Published NSL recognition is almost entirely static and pixel-based. None feeds numeric landmark sequences to a temporal model to recognise motion-based signs.
    \item NSL recognition results are reported without separating signers between training and test, so published accuracies do not establish how the systems behave on an unseen person.
    \item No existing NSL system produces both text and spoken output, and none addresses what should happen when the input is not a known sign at all.
\end{enumerate}

\section{Related Theories}

\subsection{Emergency Phrases as Dynamic, Multi-Sign Sequences}
Fingerspelling spells a word letter by letter using held handshapes. An emergency phrase is a different object: a complete communicative act performed as a continuous movement. A phrase such as \textit{I can't breathe} or \textit{The building is on fire} involves both hands moving through characteristic trajectories, shifts in posture, and transitions between component signs, all spread across many frames. No single still image contains the phrase. The information is in the sequence, which is why each phrase is recorded as a short clip, converted to a sequence of per-frame vectors, and classified as a whole.

The natural NSL form of a phrase is also not a word-for-word rendering of its English translation. \textit{I can't breathe} is not signed as three sequential signs for ``I'', ``can't'', and ``breathe''; it may be one or two signs. Establishing the natural form of each phrase with a Deaf expert was therefore a prerequisite to recording anything, and the expert's performance became the reference that every signer reproduced.

\subsection{Landmark Extraction with MediaPipe Holistic}
The central design decision is to represent each frame as a compact vector of body and hand landmarks instead of raw pixels. MediaPipe Holistic \cite{zhang2020mediapipe, mediapipeholistic2020} is a pretrained pipeline that tracks several components in a single frame:

\begin{itemize}
    \item Body pose: 33 landmarks covering the upper body, each with $x$, $y$, $z$ coordinates, giving 99 numbers.
    \item Left hand: 21 landmarks at the wrist and finger joints, giving 63 numbers.
    \item Right hand: 21 landmarks in the same layout, giving 63 numbers.
    \item Face: 468 landmarks, excluded from this project.
\end{itemize}

\noindent The three components that are used are concatenated in a fixed order to produce the 225-value feature vector used throughout the project:
\[
    \mathbf{v} = [\underbrace{v_0,\dots,v_{98}}_{\text{pose (99)}},\;
                  \underbrace{v_{99},\dots,v_{161}}_{\text{left hand (63)}},\;
                  \underbrace{v_{162},\dots,v_{224}}_{\text{right hand (63)}}] \in \mathbb{R}^{225}.
\]
When a hand or the pose is not detected in a frame, that block is filled with zeros, so every frame produces exactly 225 values regardless of what was visible.

\subsubsection{Why Pose Landmarks Are Included}
Several of the target phrases involve arm trajectories and upper-body posture that hand shape alone does not capture. A 21-point hand mesh would record the shape of the hand but not where the arm carried it, and a sweeping fire-reporting gesture would become difficult to separate from a distress call. Including the 33-point pose mesh gives the model the motion arc of the arms and torso.

\subsubsection{Why Face Landmarks Are Excluded}
Facial expression carries grammatical meaning in sign languages generally. Including all 468 face points would add roughly 1{,}400 numbers per frame and increase the feature vector more than sevenfold. Before the dataset was recorded, the NSL consultants were asked directly whether facial expression changes or adds meaning for any of the six target phrases. They confirmed it does not for this particular phrase set, so the face block was left out. This is a property of these six phrases and not a general claim about NSL.

\subsubsection{Why Landmarks and Not Pixels}
The landmark representation was chosen for three reasons. A model over 225 values per frame can be learned from a few hundred clips, where a pixel-based network would need far more. Landmarks discard background, lighting, and appearance, which are the factors that cause a pixel-trained model to fail in a room it has not seen. The resulting model is small enough to train on a laptop and to run without a GPU.

\subsection{Dual-Anchor Landmark Normalisation}
\label{sec:normalisation}
Raw landmark coordinates depend on where the signer stands and how far they are from the camera. Neither changes the meaning of the phrase, so both are removed before the data reaches the model.

\subsubsection{Hand Normalisation}
Each hand's 21 points are translated so the wrist (landmark~0) is the origin, then divided by the distance from the wrist to the base of the middle finger (landmark~9). This makes the hand representation invariant to its position in the frame and to its apparent size:
\[
    \hat{\mathbf{h}}_i = \frac{\mathbf{h}_i - \mathbf{h}_0}{\|\mathbf{h}_9 - \mathbf{h}_0\| + \varepsilon},
    \quad i = 0,\dots,20,
\]
where $\varepsilon$ is a small constant guarding against division by a near-zero scale.

\subsubsection{Pose Normalisation}
The 33 pose landmarks are translated so the midpoint of the left shoulder (landmark~11) and right shoulder (landmark~12) is the origin, then divided by the shoulder width:
\[
    \hat{\mathbf{p}}_i = \frac{\mathbf{p}_i - \tfrac{1}{2}(\mathbf{p}_{11}+\mathbf{p}_{12})}{\|\mathbf{p}_{11}-\mathbf{p}_{12}\| + \varepsilon},
    \quad i = 0,\dots,32.
\]

Figure~\ref{fig:anchors} shows the MediaPipe Holistic landmark layouts these anchors are drawn from. Landmarks 11 and 12 and their midpoint define the pose anchor; landmarks 0 and 9 define the hand anchor and the wrist-to-middle-knuckle distance used to scale it.

\noindent Two anchors are used because one cannot do both jobs. The shoulder anchor preserves where a hand sits relative to the body, which distinguishes a sign made at the chest from one made at the side. The wrist anchor captures finger configuration independently of where the hand is. Normalising the whole 225-value vector against a single anchor would lose one or the other.

Both blocks map a zero input to a zero output, which matters later: an undetected block and a padded frame are both exactly zero and can be treated identically.

\subsection{Sequence Standardisation}
A recurrent classifier needs every input to have the same number of time steps, but signers take different amounts of time to perform the same phrase. Every clip is therefore standardised to a fixed length, \textsc{seq\_len}. The value is measured from the recorded data instead of assumed: the frame-count distribution across all clips is computed and the 95th percentile is taken.

\begin{itemize}
    \item A clip longer than \textsc{seq\_len} is subsampled at \textsc{seq\_len} evenly spaced positions across its full duration, so the whole performance is still represented.
    \item A clip shorter than \textsc{seq\_len} is zero-padded at the end, never looped, with a boolean mask recording which frames are real.
\end{itemize}

\noindent The 95th percentile is preferable to the maximum because a small number of unusually long clips would otherwise force every other clip to be padded out to their length, filling the tensor with padding that carries no signal.

\subsection{The LSTM Cell and the Bidirectional LSTM}
A Long Short-Term Memory network is a recurrent network designed to carry information across many time steps without the vanishing gradients of a plain recurrent network \cite{hochreiter1997lstm}. At each step $t$ the cell keeps a cell state $c_t$ and a hidden state $h_t$, and uses a forget gate $f_t$, an input gate $i_t$, and an output gate $o_t$ to control what is discarded, added, and exposed:
\begin{align}
    f_t &= \sigma(W_f x_t + U_f h_{t-1} + b_f), \\
    i_t &= \sigma(W_i x_t + U_i h_{t-1} + b_i), \\
    o_t &= \sigma(W_o x_t + U_o h_{t-1} + b_o), \\
    \tilde{c}_t &= \tanh(W_c x_t + U_c h_{t-1} + b_c), \\
    c_t &= f_t \odot c_{t-1} + i_t \odot \tilde{c}_t, \\
    h_t &= o_t \odot \tanh(c_t),
\end{align}
where $x_t \in \mathbb{R}^{225}$ is the normalised 225-value vector at step $t$, $\sigma$ is the logistic sigmoid, $\odot$ is element-wise multiplication, and $W$, $U$, $b$ are learned.

A standard LSTM reads in one direction, so its representation at step $t$ depends only on the past. A bidirectional LSTM runs two such networks over the same sequence, one forward and one backward, and concatenates their hidden states \cite{graves2005bilstm}. This suits multi-sign phrases, where the end of a phrase often disambiguates its opening. Two phrases in this set begin with similar upward hand motion and separate only later; a forward-only model must commit to an interpretation of the opening before it has seen what follows.

\subsection{Classification and Confidence Thresholding}
The final hidden representation is passed to a fully connected layer with a softmax activation, converting raw scores $z_k$ into a distribution over the $K = 7$ classes:
\begin{equation}
    p_k = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}, \qquad k = 1,\dots,7.
\end{equation}
The predicted class is $\hat{k} = \arg\max_k p_k$ and $\max_k p_k$ is the confidence. Training minimises the categorical cross-entropy against the true label.

At inference the system emits a phrase only when the confidence exceeds a threshold and stays silent otherwise. For a tool that announces emergencies, a wrong announcement is worse than no announcement, so the asymmetry is deliberate. A softmax over seven classes is also closed-world: it distributes probability across the classes it knows and has no direct way to express that an input resembles none of them \cite{scheirer2013openset}. This is the reason the negative class described in Section~\ref{sec:phase0} is part of the model itself rather than a filter bolted on afterwards: giving the classifier explicit examples of non-signing motion during training is what lets the confidence threshold do useful work against inputs that are not a sign at all.

\subsection{Signer-Independent Evaluation}
How a recognition system is evaluated determines what its accuracy means. If clips are split into training and test sets at random, clips from the same person appear on both sides. The model can then reach a high test score by recognising individuals rather than signs, and the number says nothing about a new user. This is a form of data leakage \cite{kohavi1995crossval}, and it is the weakness identified in the closest prior NSL work \cite{shrestha2024nsl}.

The alternative used here is leave-one-signer-out (LOSO) evaluation. Every clip is tagged with the identity of the person who recorded it. For each signer in turn, the model is trained on all clips from the other signers and tested only on that signer's clips. Every clip is scored exactly once, by a model that never saw its signer. The mean across folds estimates accuracy on a new person, which is the quantity that matters for a tool intended for public use.

A signer can be held out only if every class is still present after their clips are removed, since a model cannot be fairly scored on a class it never saw.
